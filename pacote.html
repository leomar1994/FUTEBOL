🧰 Gerador do pacote de times

Monta os times reais das Séries A, B e C (e D, se a API liberar) com os elencos atuais, usando a sua conta grátis da API-Football. Tudo acontece neste navegador: a sua chave não vai para o jogo, para o GitHub nem para ninguém.

1. Sua chave da API-Football

Crie a conta grátis em dashboard.api-football.com → Account → My Access → copie a API Key.

2. Baixar os elencos

O plano grátis tem 100 pedidos por dia. São cerca de 65 pedidos para as Séries A, B e C (e mais 96 para a D). Se o limite acabar, o progresso fica salvo: volte depois das 21h (horário de Brasília) e toque em "Continuar".

Pronto para começar.

3. Usar no jogo

Times sem elenco baixado ainda entram no jogo com jogadores gerados automaticamente.

Para todo mundo jogar com os times reais (inclusive online), mande o arquivo brasil.json para o Claude colocar no repositório.
